# 规则怪谈系统 (Rule Fiction System)

一个为 SillyTavern 设计的规则怪谈游戏插件，通过侧边栏界面管理规则卡片。

## 功能特色

### 规则管理
- **侧边栏面板** - 右侧滑出式设计，不遮挡主界面
- **规则卡片** - 点击展开/收起规则内容
- **自定义编辑** - 添加、编辑、删除规则
- **多种颜色** - 默认/警告(红)/信息(蓝)/注意(黄)/安全(绿)
- **数据持久** - 规则存储在本地存储中

### 界面设计
- **极简风格** - 黑白配色，干净利落
- **响应式** - 适配各种屏幕尺寸
- **流畅动画** - 侧边栏滑入滑出效果

## 安装方法

### 方法一：通过 SillyTavern 扩展管理器（推荐）

1. 打开 SillyTavern，点击右上角的 **扩展** 图标 (🎲)
2. 在扩展页面中，点击 **Download Extension / Update** 按钮
3. 将仓库链接粘贴到输入框内
4. 点击 `Download` 进行安装
5. 安装完成后，在扩展列表中启用 "规则怪谈系统"

### 方法二：手动安装

1. 下载本项目的所有文件
2. 将文件夹复制到 SillyTavern 的扩展目录：
   ```
   SillyTavern/public/scripts/extensions/third-party/rule-fiction-system/
   ```
3. 重启 SillyTavern
4. 在扩展设置中启用插件

## 使用说明

1. **启用插件** - 在扩展设置中勾选启用
2. **打开侧边栏** - 点击右下角的 **R** 按钮
3. **添加规则** - 点击 "+ 添加规则" 按钮
4. **管理规则** - 点击规则卡片展开/收起，或编辑/删除

## 配置选项

在扩展设置中可以：
- 启用/禁用插件
- 侧边栏状态自动保存

## 技术特性

- 使用 SillyTavern 内置 jQuery
- z-index 管理避免与其他插件冲突
- 数据存储在 localStorage 中
- 清理函数支持卸载

## 问题反馈

如遇问题：
1. 检查浏览器控制台是否有错误信息
2. 确认 SillyTavern 版本兼容性
3. 尝试禁用其他扩展排查冲突
